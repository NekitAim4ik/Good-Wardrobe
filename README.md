# Добрый Шкаф

Веб-платформа пунктов приёма и обмена вещей. Подробности: `docs/architecture.md`.

## Требования
- Node.js 20 или новее (https://nodejs.org), вместе с ним ставится npm
- Git (по желанию)

## Установка и запуск
```bash
cd frontend
npm install        # установка зависимостей
npm run dev        # режим разработки → http://localhost:5173
```

Другие команды:
```bash
npm run build      # проверка типов и production-сборка в frontend/dist
npm run preview    # локальный просмотр собранной версии
```

## Ассеты
Положите фото для первого экрана в `frontend/public/images/hero.jpg`
(экспорт из Figma, примерно 1200×900, до 300 КБ). Пока файла нет, показывается зелёная заглушка.
