# Добрый Шкаф

Веб-платформа пунктов приёма и обмена вещей. Подробности: `docs/architecture.md`.

## Требования
- Node.js 20 или новее (https://nodejs.org), вместе с ним ставится npm
- PostgreSQL 14+ (локально или облачный, например Neon/Supabase). 

## Установка и запуск
```bash
cd backend
npm install
cp .env.example .env        # заполните DATABASE_URL и JWT_ACCESS_SECRET (подсказка внутри файла)
npm run db:migrate          # создаст таблицы (при первом запуске спросит имя миграции, например init)
npm run start:dev           # http://localhost:3000/api

cd frontend
npm install        # установка зависимостей
npm run dev        # режим разработки -> http://localhost:5173
```

## Что сделано
- Неделя 2: главный экран (шапка, первый экран, преимущества, два способа, вещи рядом).
- Неделя 1: вход и регистрация — `/login`, `/register`.
  Данные пока хранятся в `localStorage` браузера (имитация сервера), пароли открытым текстом — только для учёбы.
  Шапка показывает «Войти» гостю и аватар с кнопкой «Выйти» вошедшему.
- Остальные кнопки и ссылки пока ничего не открывают.
